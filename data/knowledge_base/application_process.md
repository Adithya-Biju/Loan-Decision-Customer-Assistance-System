# Loan Application Process

> Document type: Synthetic reference policy
> Policy domain: Application Process
> Version: 1.0
> Note: This document is fictional and created for the HDFC Loan Intelligence demonstration system.

## Overview

The loan application process consists of multiple stages.

A typical process includes:

1. Application submission.
2. Initial eligibility screening.
3. Document collection.
4. Identity and information verification.
5. Financial assessment.
6. Credit assessment.
7. Loan-specific review.
8. Human or institutional decision review.
9. Communication of the outcome.
10. Disbursement where applicable.

## Stage 1: Application Submission

The applicant provides information including:

- Personal information.
- Employment information.
- Income information.
- Requested loan amount.
- Loan purpose.
- Existing financial obligations.

## Stage 2: Eligibility Screening

Initial screening may evaluate:

- Age.
- Income.
- Employment status.
- Requested loan amount.
- Basic credit indicators.

Applications that clearly lack required information may be returned for completion.

## Stage 3: Documentation

Required documentation is collected based on the applicant and loan type.

Incomplete documentation may delay processing.

## Stage 4: Verification

Information provided by the applicant may be verified.

Verification can include identity, employment, income, and other application details.

## Stage 5: Financial Assessment

Financial assessment considers repayment capacity.

Relevant indicators include:

- Income.
- Existing EMIs.
- DTI.
- LTI.
- Household income.
- Existing obligations.

## Stage 6: Credit Assessment

Credit assessment may consider:

- CIBIL score.
- Credit history.
- Previous loans.
- Default history.

## Stage 7: Review

The complete application is reviewed using applicable criteria.

Cases with significant risk indicators, incomplete information, or conflicting data may require manual review.

## Stage 8: Decision Communication

The applicant should receive appropriate communication regarding the application outcome or additional information required.

The AI assistant must not represent an AI-generated recommendation as a final institutional lending decision.

## Processing Delays

Processing may take longer when:

- Documentation is incomplete.
- Verification is pending.
- Information conflicts.
- Additional review is required.
- External verification is unavailable.
